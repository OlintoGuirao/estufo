# Ícones Estufoo

Logo oficial (T-Rex com capelo) para site e APK.

| Arquivo | Uso |
| --- | --- |
| `../public/logo.png` | Logo da página / OG |
| `../public/favicon.png` | Favicon do browser |
| `../public/icons/icon-192.png` / `icon-512.png` | PWA / atalho |
| `../public/manifest.webmanifest` | Web app manifest |
| `icon.png` | Fonte para gerar ícones nativos |
| `android/icon/ic_launcher.png` | Ícone do launcher Android (APK) |

Ao integrar Capacitor/Cordova, use `resources/icon.png` (ou `android/icon/ic_launcher.png`) como ícone do app.
