# APK Estufoo

- **Estufoo-debug.apk** — build debug (instalação direta no celular).
- O app abre `https://estufo.vercel.app` no WebView (Capacitor).

## Gerar de novo

```bash
npm run cap:sync
npm run apk:debug
```

Saída Gradle: `android/app/build/outputs/apk/debug/app-debug.apk`  
Cópia: `releases/Estufoo-debug.apk`
